# Matrix Detective

## What does it do?

- Firstly, the program asks the user for the square matrix's size.
- Then you input a value for each position in the matrix.
- Then you are displayed your customized matrix.
- And given the option of using various features:
  - Searching for a value
  - The main diagonal sum
  - The secondary diagonal sum
  - Largest value in the matrix
  - Transpose of the matrix
  - Count of values above a threshold (your chosen threshold)
